# GitHub Profile ASCII

A specialized variant of the ASCII generator dedicated to generating profile art ready for your GitHub README (in dark mode).

## Features
- Locks width perfectly to `54` chars, ensuring it renders without horizontal scrolling or wrapping on GitHub.
- Configures height matching precisely adjusted for monospace `line-height` anomalies on GitHub (`0.45` multiplier).
- Specifically leverages the **Pointillism** charset (`  .·:∵∴∷•`) because it blends smoothly and elegantly into dark-themed backgrounds.

## File
- `github_ascii.py`

## Usage
```powershell
python github_ascii.py <image.jpg> [output.txt]
```
